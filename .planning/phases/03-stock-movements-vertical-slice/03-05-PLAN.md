<query-count-strategy>
**Zero-N+1 evidence (MOVE-09):** the most credible verification is asking Postgres itself how many statements it ran. Use one of these two methods (try (a) first, fall back to (b) if config-reload semantics make it impractical):

(a) **`pg_stat_statements` snapshot** (preferred — non-invasive):
```bash
# Enable extension once
docker compose exec -T postgres psql -U stockeasy -d stockeasy -c "CREATE EXTENSION IF NOT EXISTS pg_stat_statements;"
# Reset counters
docker compose exec -T postgres psql -U stockeasy -d stockeasy -c "SELECT pg_stat_statements_reset();"
# Hit the endpoint
curl -fsS "http://localhost:8080/api/stock-movements?pageSize=20" > /dev/null
# Count distinct statements that touched stock_movements (within the last second)
docker compose exec -T postgres psql -U stockeasy -d stockeasy -c "SELECT query, calls FROM pg_stat_statements WHERE query ILIKE '%stock_movements%' AND query NOT ILIKE '%pg_stat%' ORDER BY query;"
```
Acceptance: exactly 2 rows in the final SELECT — one `SELECT … FROM stock_movements m INNER JOIN products p …`, one `SELECT COUNT(*) … FROM stock_movements m INNER JOIN products p …`. `calls` should be 1 on each. If extension cannot be loaded (requires `shared_preload_libraries`), use (b).

(b) **Statement logging** (fallback):
```bash
docker compose exec -T postgres psql -U stockeasy -d stockeasy -c "ALTER SYSTEM SET log_statement = 'all';" 
docker compose exec -T postgres psql -U stockeasy -d stockeasy -c "SELECT pg_reload_conf();"
docker compose logs --since 1s postgres > /dev/null   # clear buffer
curl -fsS "http://localhost:8080/api/stock-movements?pageSize=20" > /dev/null
# Wait a beat for log flush
sleep 1
docker compose logs --since 5s postgres | grep -E "FROM stock_movements|FROM\s+stock_movements" | grep -v "pg_stat" | wc -l
```
Acceptance: count is exactly 2.

Whichever method you use, capture the raw output into `03-VERIFICATION.md` as evidence.
</query-count-strategy>
